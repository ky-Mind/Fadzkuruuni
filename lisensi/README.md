# FOLDER LISENSI — FADZKURUUNI

Folder ini dibuat untuk menyimpan dokumentasi hak penggunaan, sumber, atribusi,
dan hasil penelusuran identitas Fadzkuruuni.

## Isi

- `LISENSI-PROYEK.md` — status lisensi kode proyek.
- `LISENSI-KONTEN.md` — status hak penggunaan konten keagamaan.
- `SUMBER-DAN-ATRIBUSI.md` — sumber web dan aturan atribusi.
- `PROFIL-FADZKURUUNI.md` — hasil penelusuran identitas/lokasi pesantren.
- `CONTENT-SOURCE-REGISTER.csv` — daftar kategori konten dan sumber rujukannya.
- `NOTICE.md` — pemberitahuan singkat untuk distribusi paket.

Paket ini menggunakan prinsip konservatif: jika izin penggunaan ulang belum
terverifikasi, konten dianggap sebagai bahan referensi dan bukan otomatis bebas
didistribusikan.
