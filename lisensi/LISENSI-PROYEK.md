# LISENSI PROYEK FADZKURUUNI

Status: BELUM DITETAPKAN

Dokumen ini sengaja tidak menetapkan lisensi open-source tertentu untuk kode proyek
tanpa keputusan eksplisit dari pemilik proyek.

## 1. Kode aplikasi

Folder `fadzkuruuni/` berisi kode aplikasi yang diberikan dalam paket proyek ini.
Hak penggunaan, pengubahan, dan pendistribusian kode mengikuti hak pemilik proyek,
kecuali jika pemilik proyek kemudian menetapkan lisensi yang berbeda.

Jangan menambahkan label MIT, Apache-2.0, GPL, atau lisensi open-source lain ke proyek
ini sebagai fakta tanpa persetujuan pemilik proyek.

## 2. Konten keagamaan

Folder `aset/` berisi materi bacaan/teks keagamaan yang dikumpulkan untuk kebutuhan
aplikasi. Kehadiran suatu teks di paket ini TIDAK berarti teks tersebut bebas hak cipta
atau telah diberikan izin redistribusi oleh situs, penerbit, penyusun, penerjemah,
atau pemegang hak terkait.

Untuk setiap publikasi ulang, periksa:
- sumber asli;
- edisi kitab;
- penerjemah/transliterasi;
- hak cipta penerbit;
- ketentuan penggunaan situs sumber;
- izin pemilik konten jika diperlukan.

## 3. Sumber

Daftar sumber dan hasil penelusuran Pondok Pesantren Fadzkuruuni terdapat pada:
- `SUMBER-DAN-ATRIBUSI.md`
- `PROFIL-FADZKURUUNI.md`
- `CONTENT-SOURCE-REGISTER.csv`

## 4. Prinsip atribusi

Jika konten dari sumber pihak ketiga tetap digunakan setelah verifikasi izin,
cantumkan nama sumber secara jelas dan jangan menghapus pemberitahuan hak cipta
yang menyertainya.

Dokumen ini adalah catatan lisensi/provenance proyek, bukan nasihat hukum.
